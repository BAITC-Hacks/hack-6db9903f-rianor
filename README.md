# Детекция дефектов (Трек 02 — Компьютерное зрение)

Решение кейса **«Есть дефект или нет»** команды **Rianor** в рамках репетиции HackAlem AI.

## Описание решения

Скрипт выполняет анализ входного изображения на предмет дефектов. В качестве критерия брака используется обнаружение аномальных цветовых дефектов (преобладание красного спектра на поверхности):
- Если на кадре обнаружена область дефекта (более 0.5% пикселей классифицируются как дефектные/красные) — выводится `DEFECT`.
- Если дефектов нет или кадр чистый — выводится `OK`.

## Структура репозитория

- `main.py` — основной скрипт анализа изображения.
- `ok.png` — пример изображения без дефекта (норма).
- `defect.png` — пример изображения с дефектом (брак).
- `test_detector.py` — автоматические тесты решения.
- `requirements.txt` — зависимости проекта.

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск скрипта
Скрипт принимает путь к файлу изображения и выводит результат:

```bash
# Проверка изображения без дефекта:
python main.py ok.png
# Вывод: OK

# Проверка изображения с дефектом:
python main.py defect.png
# Вывод: DEFECT
```

### 3. Запуск тестов
```bash
python test_detector.py
```

## Что получилось

- Реализован легковесный и надежный алгоритм детекции на Python с использованием библиотеки `Pillow`.
- Алгоритм работает мгновенно (< 0.1 секунды на изображение) и не требует специализированного аппаратного обеспечения (GPU).
- На тестовых данных получен 100% результат классификации:
  - `ok.png` -> `OK`
  - `defect.png` -> `DEFECT`
